========================================================================
  PETRASUR — SITIO WEB
  Guía de instalación local y mantenimiento (para principiantes)
========================================================================

Este documento explica, paso a paso, cómo ver tu página web en tu propio
computador ("en local") y cómo hacer los cambios más comunes.

No necesitas saber programar para seguir esta guía. Solo sigue los pasos
en orden.


------------------------------------------------------------------------
1. ¿QUÉ HAY EN ESTA CARPETA?
------------------------------------------------------------------------

La carpeta del sitio se llama  Petra  y contiene:

  index.html            -> Página de Inicio
  nosotros.html         -> Página Nosotros
  producto.html         -> Página Producto (Concrete Blanket)
  aplicaciones.html     -> Página Aplicaciones
  galeria.html          -> Página Galería de obras
  contacto.html         -> Página Contacto
  robots.txt            -> Archivo para buscadores (SEO)
  sitemap.xml           -> Mapa del sitio para buscadores (SEO)
  generar_galeria.py    -> Script que arma la galería automáticamente
  LEEME.txt             -> Este archivo

  assets/
    css/styles.css      -> Los estilos (colores, tipografía, diseño)
    js/main.js          -> Funcionamiento (menú, galería, formulario)
    js/galeria-data.js  -> Lista de obras de la galería
    js/analytics.js     -> Estadísticas de visitas (opcional)
    img/                -> Imágenes (logos, fotos, diagramas)
    docs/               -> Documentos PDF descargables
    galeria/            -> AQUÍ VAN TUS FOTOS Y VIDEOS DE OBRAS


------------------------------------------------------------------------
2. ¿QUÉ NECESITO PARA VERLO EN MI COMPUTADOR?
------------------------------------------------------------------------

Solo necesitas UNA de estas tres opciones. La opción A es la más fácil.

  OPCIÓN A (RECOMENDADA): Visual Studio Code + extensión "Live Server"
  OPCIÓN B: Python instalado (ya suele venir en Linux y Mac)
  OPCIÓN C: Node.js instalado

Elige una y sigue los pasos de la sección 3.


------------------------------------------------------------------------
3. CÓMO VER LA PÁGINA EN LOCAL
------------------------------------------------------------------------

=== OPCIÓN A: Visual Studio Code + Live Server (la más simple) ===

  1. Abre Visual Studio Code.
  2. Menú Archivo > Abrir carpeta... y selecciona la carpeta Petra.
  3. En la barra lateral izquierda, haz clic en el ícono de "Extensiones"
     (los cuadraditos) o presiona Ctrl+Shift+X.
  4. Busca "Live Server" (de Ritwick Dey) e instálala.
  5. En el panel de archivos, haz clic derecho sobre index.html y elige
     "Open with Live Server".
  6. Se abrirá tu navegador en una dirección parecida a:
         http://127.0.0.1:5500/index.html
     ¡Listo! Ya estás viendo tu página.

  Ventaja: cada vez que guardes un cambio, la página se actualiza sola.


=== OPCIÓN B: Python (una sola línea de comando) ===

  1. Abre una terminal (en Linux: Ctrl+Alt+T).
  2. Escribe estos dos comandos, uno por línea, y presiona Enter:

         cd ruta/a/Petra
         python3 -m http.server 8000

     (Reemplaza "ruta/a/Petra" por la ubicación real de la carpeta.
      Si no sabes la ruta, arrastra la carpeta a la terminal.)

  3. Abre tu navegador y entra a:
         http://localhost:8000

  4. Para detener el servidor, vuelve a la terminal y presiona Ctrl+C.


=== OPCIÓN C: Node.js ===

  1. Abre una terminal.
  2. Ejecuta:

         cd ruta/a/Petra
         npx serve

  3. Abre la dirección que aparezca en pantalla (normalmente
     http://localhost:3000).


IMPORTANTE: No abras los archivos .html haciendo doble clic directamente
(con file:///...). El formulario y algunas funciones necesitan un servidor.
Usa siempre una de las opciones de arriba.

------------------------------------------------------------------------

Actualmente hay datos de ejemplo (correo y teléfono ficticios) que debes
reemplazar por los reales.

Los datos aparecen en DOS lugares:
  - El pie de página (footer) de TODAS las páginas.
  - La página de contacto (contacto.html).

Busca y reemplaza en todos los archivos .html:

  +56 9 0000 0000        -> tu teléfono real
  contacto@petrasur.cl   -> tu correo real
  Av. Concón-Reñaca N°41 Of. 2, Concón, Chile  -> tu dirección real

Además, el botón de WhatsApp usa este enlace (aparece en todas las páginas):

  https://wa.me/56900000000?text=Hola%20Petrasur%2C%20quiero%20cotizar%20Concrete%20Blanket

  Reemplaza  56900000000  por tu número real, SIN el signo + y SIN espacios.
  Ejemplo: si tu número es +56 9 5401 5223, queda:  56954015223

CONSEJO: En Visual Studio Code puedes usar "Buscar y reemplazar en
archivos" (Ctrl+Shift+H) para cambiar estos datos en todas las páginas
de una sola vez.


------------------------------------------------------------------------
5. CÓMO ACTIVAR EL FORMULARIO DE CONTACTO
------------------------------------------------------------------------

El formulario envía los mensajes al correo:  igneel.2@gmail.com
Usa un servicio gratuito llamado FormSubmit (no requiere programar).

PASOS PARA ACTIVARLO (solo la primera vez):

  1. Publica el sitio o ábrelo en local.
  2. Rellena el formulario de contacto y envíalo una vez.
  3. FormSubmit enviará un correo de confirmación a igneel.2@gmail.com.
  4. Abre ese correo y haz clic en el enlace de confirmación.
  5. ¡Listo! Desde ese momento, todos los mensajes llegarán a ese correo.

PARA CAMBIAR EL CORREO DE DESTINO:
  Abre contacto.html y busca esta línea (cerca del inicio del formulario):

      action="https://formsubmit.co/ajax/igneel.2@gmail.com"

  Reemplaza  igneel.2@gmail.com  por el correo que quieras.

NOTA: Mientras el formulario no esté confirmado, si alguien lo envía verá
un mensaje de aviso y podrá contactarte por WhatsApp o correo.

6. CÓMO AGREGAR FOTOS Y VIDEOS A LA GALERÍA
------------------------------------------------------------------------

Esta es la parte más importante para mantener la galería actualizada.

=== PASO 1: Guarda tus archivos en la carpeta correcta ===

  Carpeta:   assets/galeria/

=== PASO 2: Ponles el nombre correcto ===

  Usa SIEMPRE este formato:   obraNN_fotoMM.jpg   o   obraNN_videoMM.mp4

  Donde:
    NN  = número de la obra (01, 02, 03, ...)
    MM  = número de la foto o video dentro de esa obra (01, 02, 03, ...)

  EJEMPLOS VÁLIDOS:
    obra01_foto01.jpg
    obra01_foto02.jpg
    obra01_video01.mp4
    obra02_foto01.jpg
    obra03_foto01.jpg
    obra03_video01.mp4

  REGLAS:
    - Usa minúsculas y guion bajo (_). No uses espacios ni tildes.
    - Todas las fotos de una misma obra comparten el mismo "obraNN".
    - Formatos de imagen recomendados: .jpg o .webp
    - Formatos de video recomendados: .mp4

  PORTADA DE UN VIDEO (opcional pero recomendado):
    Si quieres que el video muestre una imagen antes de reproducirse,
    guarda una foto con el mismo número y el nombre del video:
        obra01_video01.mp4   (el video)
        obra01_video01.jpg   (la portada)


=== PASO 3: Regenera la galería ===

  Abre una terminal en la carpeta Petra y ejecuta:

        python3 generar_galeria.py

  Verás un mensaje como:
        Galería generada: .../assets/js/galeria-data.js
        Obras encontradas: 3

  Recarga la página de galería en el navegador y verás tus fotos.


=== PASO 4 (OPCIONAL): Ponle título y descripción a cada obra ===

  Abre el archivo  assets/galeria/obras.json  y edítalo. Ejemplo:

    {
      "obra01": {
        "titulo": "Revestimiento de canal de riego",
        "categoria": "canales",
        "ubicacion": "Región de Valparaíso",
        "descripcion": "Revestimiento de canal con Concrete Blanket."
      },
      "obra02": {
        "titulo": "Protección de talud ferroviario",
        "categoria": "taludes",
        "ubicacion": "Región de Valparaíso",
        "descripcion": "Estabilización de talud junto a línea férrea."
      }
    }

  Categorías disponibles (para los filtros de la galería):
    "canales", "taludes", "otros"

  Después de editar obras.json, vuelve a ejecutar:
        python3 generar_galeria.py


RESUMEN RÁPIDO PARA AGREGAR UNA OBRA NUEVA:
  1. Copia tus fotos a assets/galeria/ con nombres obra04_foto01.jpg, etc.
  2. (Opcional) Agrega la obra "obra04" en assets/galeria/obras.json.
  3. Ejecuta:  python3 generar_galeria.py
  4. Recarga la galería en el navegador.

7. CÓMO ACTIVAR LAS ESTADÍSTICAS DE VISITAS (GOOGLE ANALYTICS)
------------------------------------------------------------------------

Google Analytics te muestra cuántas personas visitan tu sitio, desde dónde
y qué páginas ven. Es gratis.

  1. Entra a https://analytics.google.com y crea una cuenta.
  2. Crea una "Propiedad" para tu sitio y copia tu ID de medición
     (tiene el formato G-XXXXXXXXXX).
  3. Abre el archivo  assets/js/analytics.js  y busca esta línea:

         var GA_ID = 'G-XXXXXXXXXX';

     Reemplaza G-XXXXXXXXXX por tu ID real.
  4. Guarda. Listo: las estadísticas empezarán a registrarse cuando el
     sitio esté publicado.

Mientras el ID siga siendo el de ejemplo, el archivo no hace nada.

8. CÓMO PUBLICAR EL SITIO EN GITHUB PAGES
------------------------------------------------------------------------

Este proyecto está preparado para publicarse en GitHub Pages en la ruta:

    https://TU-USUARIO.github.io/inventarios/Petra/

(Reemplaza TU-USUARIO por tu nombre de usuario de GitHub.)

=== PASO 1: Crear el repositorio ===
  1. Entra a https://github.com y crea una cuenta si aún no tienes.
  2. Crea un repositorio NUEVO llamado:  inventarios
     (para usar GitHub Pages gratis debe ser PÚBLICO).
  3. NO marques "Add a README" (lo subiremos nosotros).

=== PASO 2: Subir el proyecto ===
  El repositorio "inventarios" debe contener una carpeta llamada "Petra"
  con todo el sitio dentro.

  Opción fácil (sin comandos):
    1. En la página del repositorio, haz clic en "Add file" > "Upload files".
    2. Arrastra la carpeta "Petra" completa (con todo su contenido).
    3. Escribe un mensaje y haz clic en "Commit changes".

  Opción con Git (terminal):
      cd ruta/a/inventarios
      git init
      git add .
      git commit -m "Sitio Petrasur"
      git branch -M main
      git remote add origin https://github.com/TU-USUARIO/inventarios.git
      git push -u origin main

=== PASO 3: Activar GitHub Pages ===
  1. En el repositorio, entra a "Settings" > "Pages".
  2. En "Source", elige "Deploy from a branch".
  3. Branch: "main"  y  carpeta: "/ (root)". Guarda.
  4. Espera 1-2 minutos. Tu sitio quedará disponible en:
         https://TU-USUARIO.github.io/inventarios/Petra/

=== PASO 4: Ajustar las URLs (importante para SEO) ===
  Reemplaza "TU-USUARIO" por tu usuario real en:
    - sitemap.xml
    - robots.txt
    - las etiquetas <link rel="canonical">, <meta property="og:url"> y
      <meta property="og:image"> de cada archivo .html
    - 404.html (usa rutas absolutas con /inventarios/Petra/)

  CONSEJO: en Visual Studio Code usa "Buscar y reemplazar en archivos"
  (Ctrl+Shift+H) para cambiar "TU-USUARIO" en todo el proyecto de una vez.

=== PASO 5: Archivo .nojekyll ===
  En la RAÍZ del repositorio (al mismo nivel que la carpeta Petra) debe
  existir un archivo vacío llamado:  .nojekyll
  Esto evita que GitHub procese el sitio con Jekyll y acelera la publicación.
  (Ya incluimos uno dentro de Petra; si publicas solo esa carpeta como raíz,
   funcionará igual.)

=== ACTUALIZAR EL SITIO MÁS ADELANTE ===
  Cada vez que cambies archivos y hagas "push" (o subas archivos por la web),
  GitHub Pages actualizará el sitio automáticamente en 1-2 minutos.

=== DOMINIO PROPIO (OPCIONAL) ===
  Si más adelante compras un dominio (ej. www.petrasur.cl), puedes
  configurarlo en Settings > Pages > Custom domain.

  IMPORTANTE AL PUBLICAR:
    - Activa el formulario (sección 5) y Google Analytics (sección 7).

9. CÓMO EDITAR LOS TEXTOS
------------------------------------------------------------------------

  - Cada página es un archivo .html. Ábrelo con Visual Studio Code.
  - El texto visible está entre etiquetas. Por ejemplo:

        <h2>Por qué elegir Concrete Blanket</h2>
        <p>Menos tiempo, menos personal y menos costo total.</p>

    Cambia solo lo que está ENTRE las etiquetas > y <.
  - No borres las etiquetas ni las comillas.
  - Guarda el archivo y recarga la página para ver el cambio.

  Los colores y el diseño se controlan en  assets/css/styles.css
  (al inicio del archivo, en la sección ":root", están los colores de
  la marca).


------------------------------------------------------------------------
10. PREGUNTAS FRECUENTES / PROBLEMAS COMUNES
------------------------------------------------------------------------

  ¿La página se ve sin estilos o sin imágenes?
    -> Asegúrate de abrirla con un servidor (sección 3), no con doble clic.

  ¿El formulario no envía?
    -> Falta confirmar el correo en FormSubmit (sección 5). Mientras tanto,
       usa el botón de WhatsApp.

  ¿Agregué fotos pero no aparecen en la galería?
    -> Revisa que los nombres sigan el formato obraNN_fotoMM.jpg y que
       hayas ejecutado  python3 generar_galeria.py.

  ¿Cómo cambio el logo?
    -> Reemplaza los archivos en assets/img/logos/ manteniendo los mismos
       nombres (petrasur-logo-horizontal.png, petrasur-logo-vertical.png,
       y las versiones "-blanco" para el pie de página).

  ¿Cómo cambio el número de WhatsApp?
    -> Busca "wa.me/56900000000" en los archivos .html y reemplázalo
       (sección 4).

  ¿Dónde cambio el correo del formulario?
    -> En contacto.html, en el atributo action del formulario (sección 5).
